A reel with a local `.mp4` plays inline on the page (muted, on hover/tap).
A reel without one falls back to its stock cover and opens Instagram.
The cover is optional — the video's own first frame is used if omitted.

Keep clips short and compressed (720x1280, ~2-4 MB) so the page stays fast.
